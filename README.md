# E-commerce Sales Analysis

## Project Overview

This project analyzes a fictional e-commerce sales dataset using Excel, SQL, and Python/Pandas.

The goal is to identify sales trends, profitable products, regional performance, and other useful business insights.

## Tools Used

- Microsoft Excel
- SQL
- Python
- Pandas
- Google Sheets

## Dataset

The dataset contains 300 fictional e-commerce orders from 2025.

It includes:

- Order ID
- Order Date
- Product
- Category
- Region
- Sales Channel
- Quantity
- Unit Price
- Discount
- Gross Sales
- Net Sales
- Cost
- Profit
- Profit Margin

## Analysis Performed

### Excel

I used Excel to:

- Sort and filter sales data
- Organize the dataset
- Summarize monthly sales
- Analyze product performance
- Compare regional sales
- Calculate sales and profit

### SQL

I used SQL to:

- Calculate total sales and profit
- Analyze sales by product
- Analyze sales by region
- Analyze monthly sales
- Calculate profit margins
- Identify high-margin products

### Python

I used Python and Pandas to:

- Load the dataset
- Organize and process the data
- Calculate sales and profit
- Group data by product and region
- Identify trends and business insights

## Business Questions

The project answers questions such as:

1. What is the total sales revenue?
2. What is the total profit?
3. Which product generates the most sales?
4. Which region generates the most sales?
5. Which products have the highest profit margins?
6. How do sales change over time?
7. Which products should receive more attention?
